# Open Questions

A routing table, not a to-do list: every row is a question the vault is
listening for an answer to. When a session turns up something that answers,
refines, or contradicts a row, it links it here — the check happens while the
work is fresh, not in a later pass. No owners, no due dates. Only the owner,
and a session acting on their say-so, edits this file.

A row leaves this table when it closes — `answered` (with the evidence that
closed it) or `abandoned` (deliberately dropped) — and moves to a
`open-questions-closed` note. Nothing is ever deleted; the always-loaded tier
just stays small. A new durable question gets a new row here rather than being
buried in a note nobody opens again.
